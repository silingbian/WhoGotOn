# 谁上车了？视觉记忆游戏

一个纯前端的视觉追踪训练小游戏：先记住站台上的动物，再猜哪一只能坐上公交车。无依赖、无构建，浏览器直接打开即可运行。

## 玩法

1. **等待阶段**：站台随机出现若干只小动物（默认 5 只），倒计时结束后公交车驶来。
2. **公交停留**：公交车停靠遮挡住动物一段时间后驶离，随机一只动物"上车"消失。
3. **揭晓答案**：点击「下一轮」查看上车的动物，随后自动开始新的一轮。

## 设置（右上角「设置」按钮）

| 设置项 | 范围 | 默认 |
| --- | --- | --- |
| 动物出场数 | 3–10 只 | 5 只 |
| 公交停留 | 0–60 秒（0 秒即进站立刻驶离） | 1 秒 |
| 等待时间（公交到来前） | 1–100 秒 | 15 秒 |

> 相邻两轮的动物不会重复，因此动物素材总数需 ≥ 出场数的 2 倍。

## 本地运行

直接双击 `index.html`，或用任意静态服务器：

```bash
# Python
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 目录结构

- `index.html`  — 页面结构
- `styles.css`  — 样式与移动端适配
- `game.js`     — 游戏逻辑
- `assets/`     — 动物素材、公交车底图等
- `assets/animals/catalog.js` — 动物清单，可直接在此登记新动物

## 素材说明

- 位图素材已统一压缩为 **WebP**（长边 600px，保留透明背景），约从 141 MB 压缩到 3 MB。
- 高清原图归档在 `image/original/`，不参与页面加载，已加入 `.gitignore` 防止误提交到仓库。
- SVG 素材（矢量）体积很小，保持原样。

## 新增动物素材

把图片放进 `assets/animals/`（推荐透明背景、接近 180×200 竖版，或直接使用 WebP），然后在右上角「动物」弹窗中点击「添加动物」填写名称与文件名，最后「保存到 catalog.js」。

- 位图建议直接提供 `.webp` 文件；如使用 `.png/.jpg` 也会正常加载。
- 若某条目加载失败需要回退原图，游戏会自动使用 `catalog.js` 中该条目的 `fallback` 字段（当前由压缩工具自动生成）。

详情见 `assets/animals/README.md`。

## 线上部署

本仓库为纯静态资源，可直接部署到任意静态托管平台：

- **Vercel** / **Netlify** / **Cloudflare Pages**：连接到本仓库即可自动部署，构建命令留空（目录选根目录即可）。
- **GitHub Pages**：仓库 Settings → Pages，选择部署分支。

> 高清原图等源素材统一放在 `image/original/`，已通过 `.gitignore` 排除，上述基于 Git 的自动部署不会带上它们。若使用 **Vercel CLI**（`vercel`）或"把整个目录直接上传"的方式部署，请使用仓库根目录的 `.vercelignore`（已提供，排除 `image/original/`）；其他支持整目录上传的托管，请在打包/上传时剔除 `image/` 目录。
